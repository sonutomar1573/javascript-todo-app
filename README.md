# Section 3 — TaskFlow To-do App

A browser-based task manager with task creation, completion, deletion, filters, clear-completed, responsive styling, and automatic local storage persistence.

## Run
Open `index.html` in a browser.

## Features
- Add and delete tasks
- Mark tasks complete
- Filter all, active, completed
- Clear completed tasks
- Saves tasks with localStorage
- Responsive layout and accessible labels

Built with HTML, CSS and vanilla JavaScript.
